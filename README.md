## What I build

### AI agents & agentic workflows

- **Agents that work with application data** — query databases, retrieve relevant records, and turn the results into useful, contextual answers through natural language.
- **Agentic coding workflows** — AI-driven flows that generate code and carry out programming tasks, including agents that write parsers to extract structured data from external sources.
- **Tool-using AI assistants** — connect language models to application capabilities so they can search, retrieve information, and perform actions within a product.
- **Document intelligence** — build pipelines for OCR, embeddings, and hybrid search, plus AI workflows that analyse source documents and generate structured summaries.

### Full stack product engineering

- **SaaS and operational platforms** — multi-tenant applications, billing systems, customer management, admin dashboards, and internal tools.
- **Web and mobile applications** — React and Next.js interfaces, React Native apps, complex editable tables, data-heavy workflows, and real-time features.
- **Connected product workflows** — messaging, notifications, e-signatures, authentication, access control, imports, and exports.

### Architecture, data & infrastructure

- **Backend and API design** — typed APIs, database modelling, ORM migrations, query optimisation, and integrations with external services.
- **Asynchronous systems** — workers and job pipelines for document processing, embeddings, emails, and AI tasks using Cloud Run and Inngest.
- **Platform modernisation** — migrate legacy systems into modular monorepos, improve authentication and storage, and establish CI/CD, monitoring, and backup workflows.
